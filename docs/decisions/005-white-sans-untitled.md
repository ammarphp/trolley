# White surfaces, sans-serif type, untitled dilemmas

23 September 2026. The owner specified three rules for the current campaign and local review concepts: white surfaces except limited highlights, exclusively sans-serif type, and no scenario labels or titles. These rules supersede the earlier tinted and dark page treatments. The layout alternatives remain open for later review.

The campaign keeps white page, panel, prompt and control surfaces throughout every world state. Its original vector art uses white paper, neutral ink and material shading, with restrained red action/consequence highlights. Damage and loss of control remain visible in the world without changing the page into a colored or dark theme.

Scenario names remain internal content metadata for unchanged replay compatibility. The prompt, detail panel, run record and ending callbacks do not display them. The prompt region retains its accessible name, keyboard focus and complete spoken text. History identifies the chosen action. The existing browser test now checks prompt continuity rather than a deleted heading.

Local mockups and visual audits remain excluded from Git and Pages. The archived legacy version remains a separate compatibility tool; this change applies to the current campaign interface.
