# Run analysis templates

These are analysis specifications for the implemented records, not participant findings. Run `pnpm replay exported-replay.json verified-summary.json` to validate a local slice replay before deriving a summary. Incompatible content is rejected. `pnpm inspect:content` reports executable nodes, dependencies and source links without promoting draft material.

## One run

Report requested action, executed action, executor and status side by side. Plot fictional GDP, casualties and capability on separately labeled axes against committed decision number. Show dates only as fictional dates. Add causal event annotations, permissions granted/revoked, and the ending predicates that were satisfied. Describe a trajectory; do not infer a stable moral personality or a counterfactual effect from one path. The in-game debrief currently implements two of these plots and its decision record.

## Comparable recorded choices

Use only approved story profiles and free human actions. Group by exact versioned comparison key, including presentation, advice exposure, side order, default route, authority scope and prepared observations. Count at most one contribution per run/cell. Show the number of eligible runs, executed semantic-option counts, publication time and suppression rule. Twenty runs is a publication threshold, not statistical significance. A run is not a unique person. Do not combine old versions, forced events, test traffic or development slices to increase denominators.

## Exposure and completion

Within an authorized private analysis, count exposed, advised, committed, withdrawn, incomplete and ended runs separately. Choose and state a completeness definition before analysis. Public aggregate cells alone cannot recover the exposure denominator or explain dropout. Do not label absent data as a refused choice, completion, or default action. Never infer unique users from independent run IDs.

## Advice and authority

Tabulate advice exposure alongside decisions, and requested-versus-executed divergence alongside actual authority changes. Optional advice is self-selected: an association with later choice is not an effect of advice. A visible lever move does not imply the requested action was executed. Ratification of an existing transfer and the original transfer are different causal events even when both choices execute freely within the remaining office.

## Synthetic model audit

Use the headless CLI for reachability, invariants and policy stress tests. Label all resulting tables synthetic. Retain the manifest/content hashes, seed family, policy definition, number of errors and ending witnesses. Enumeration frequency describes the chosen enumeration procedure under the authored model. It is neither a forecast nor an estimate of human preferences.

## Formal evaluation, if separately approved

Freeze content, assignment, recruitment, outcomes, exclusions, missingness, accessibility variants and the analysis before recruitment. The current story is not a randomized trial. Educational efficacy and causal claims require suitable measurement and a separately reviewed protocol. No such participant evidence is supplied by this repository.
