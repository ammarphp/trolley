# Evidence layers and evaluation

## Four separate claims

1. **Source claim:** a historical statement, philosophical argument, theorem under assumptions, bounded empirical finding, or forecast/scenario. Capture author, version, exact locator, reading scope, assumptions, and approved interpretation.
2. **Authored model:** a fictional institution, numerical parameter, causal rule, or consequence. Attach provenance to each number separately from any source cited nearby. An invented 10% incident chance remains invented even when the mechanism is research-inspired.
3. **Implementation evidence:** a test, replay hash, witness path, motion recording, or documented inspection establishes only the properties it checked.
4. **Participant evidence:** an actually collected and appropriately governed observation or study. A persuasive game, a plausible theory of learning, or a test suite is not evidence of an educational effect.

The project deliberately argues against reckless AI competition and loss of control. Its normative thesis does not authorize mislabeling fiction as empirical calibration. The model must permit real benefits, costly effective safeguards, failed safeguards, institutional cooperation, and conditional control loss. Ending frequencies from synthetic policies describe that authored model, not the probability of humanity's future.

## First research contribution: artifact and design

The initial contribution is a reproducible method for translating sourced mechanisms into embodied decisions with distinct world truth, reported evidence, and authority. Evaluate the content-review process, deterministic journal, route diversity, reproducibility, semantic coverage, source fidelity, and failure cases. A novelty claim additionally requires comparison with related ethics games, interactive safety explanations and simulation systems; this package does not claim that comparison is complete.

Publish the approved content snapshot, hashes, claim registry, parameter table, synthetic policy definitions, golden fixtures, reproducible seeds, ending witnesses, route coverage, sensitivity results, and limitations. Reproducibility does not make an authored model realistic. A catastrophe count must not become a single player morality score.

## Public story data

The unit is the run. There is intentionally no person-level deduplication or linkage. Several runs may belong to one person; observations within each run also depend on prior choices, routing, assistant use, and exposure. Exact counts are descriptive. Neither twenty run IDs nor a very large number of clicks justifies a representative-population claim or human-independent confidence interval.

Only opted-in observations after Start are eligible. Selection into sharing, route eligibility, optional advice, accessibility preferences, incomplete uploads and leaving the page affect coverage. Distinguish explicit ending, explicit withdrawal, and last observed event. Absence of an ending event does not identify boredom, distress, abandonment, or completion.

Choice time includes comprehension, deliberation, reading speed and device interruptions. It does not directly measure moral difficulty. Optional categorical reflections are missing by design and must not be imputed as disagreement or uncertainty. No raw choice diagnoses a person's character, ideology, intelligence or mental health.

## Analysis templates

| Template | Inputs and output | Interpretation limits |
|---|---|---|
| Coverage | Registered runs, consent interval, exposed nodes, committed events, ending receipts; report missingness by content/profile | Unobserved private play is outside the denominator |
| Comparable choices | First eligible response per run per exact material-context key; show option counts and n | No pooled unlike parameters, forced actions, imported sessions, or study treatments |
| Run trajectory | Authority changes, actions, advice exposure and active-time distributions within each run | Order, content and degradation intentionally covary |
| Exposure and attrition | Stage reached and last event, distinguishing explicit endings and unresolved recent runs | Avoid survivor-only claims about later stages |
| Agency ledger | Intended option, actual executor, denial/override/delegation and prior grant | An attempted choice is not an executed preference |
| Model sensitivity | Synthetic policies under authored parameter sweeps and shared exogenous draws; ending reachability | Not real-world forecasting; disclose which noise is held fixed |

Each output names the manifest/content version, source profile, exclusion rules, date window, and number of runs/events retained. Never mix synthetic runs with public observations. Public plots do not need a p-value to be useful.

## Formal-study profile: disabled until separately activated

Preparation of a frozen study profile is allowed; recruitment or collection under it is a distinct release decision. Before activation, obtain the appropriate institutional determination for the actual protocol, finalize consent/content warning/debriefing, recruitment and eligibility, retention/withdrawal, assignment, primary outcome, analysis and exclusions. This is a project gate, not a declaration that the work is exempt or an interpretation of a particular person's legal obligations. Official starting point: [Penn IRB](https://irb.upenn.edu/).

An initial study could isolate an authority mechanic with matched content, exposure and duration. Do not simultaneously change music, text, probabilities and advisor reliability and attribute the effect to embodiment. Record assignment before exposure. Account for repeated decisions, dropout, route selection and multiple comparisons. Do not define learning only as increased fear or agreement with the author's forecast. Sample size follows the eventual design and expected variation; a public display threshold supplies no power justification.

## Review evidence

Passing inventory/fixture validation verifies structure, references and coverage obligations. It does not mark nodes approved, test a runtime engine, or establish source interpretation. Independent reviewers must record decisions at the claim, semantic model, narrative, technical and playtest stages. This methods file and the v2 privacy design received author self-review; independent security and methods review remain required.
