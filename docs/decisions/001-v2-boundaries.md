# ADR001 — preserve the repository, separate the causal game

Accepted for implementation 2026-09-22. V1 remains at legacy.html with local play/export and existing withdrawal access; new v1 submissions are disabled client-side. V2 uses typed runtime contracts, deterministic headless transitions, semantic DOM and a separate Pixi WebGL scene. The new collector is disabled in build config until its public-service gate is passed.

Dependencies pinned: Pixi8.21.0, Zod4.6.5, TypeScript5.9.3. Existing esbuild and Node test infrastructure retained. No frontend framework migration.

The initial integrated development route is a14-decision compressed slice, clearly labeled. It is not the complete154-candidate campaign. Normalized service capacities (demand1000) are a recorded slice approximation. Candidate inventory and prose fixture specifications do not imply implemented/validated production content.

Aggregate refresh now builds a deployment artifact, never a count commit to repository history. Existing historical aggregates cannot be recalled. Public v2 activation remains gated on actual service ownership/logging/retention review.

Sources: owner-approved plan and execution handoff. Decision provenance and schema changes are versioned in this repository. No source PDF is bundled.
